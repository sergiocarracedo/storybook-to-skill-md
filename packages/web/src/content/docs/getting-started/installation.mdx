## Installation

Install the CLI globally using your preferred package manager:

<PackageManagerTabs
  npm="npm install -g storybook-to-skills-md"
  pnpm="pnpm add -g storybook-to-skills-md"
  yarn="yarn global add storybook-to-skills-md"
  bun="bun add -g storybook-to-skills-md"
/>

## Prerequisites

Before using the tool, ensure you have:

- **Node.js 20 or later** - Required to run the CLI
- **A Storybook project** - With accessible `index.json` file
- **LLM API key** - For OpenAI, Anthropic, or Google AI

## Verify Installation

After installation, verify the CLI is working:

```bash
storybook-to-skills-md --version
```

You should see the version number printed to the console.
