## What is Storybook to SKILL.md?

`storybook-to-skills-md` is a CLI tool that automatically generates [SKILL.md](https://agentskills.io) files from your Storybook components. These files provide AI agents with structured knowledge about your components, enabling them to use your design system effectively.

## Quick Start

Install the CLI globally:

```bash
npm install -g @sergiocarracedo/storybook-to-skills-md
```

Generate SKILL.md files from your Storybook:

```bash
storybook-to-skills-md generate \
  --storybook-url https://your-storybook.com \
  --source-dir ./src/components \
  --output-dir ./skills \
  --provider openai \
  --model gpt-4o \
  --api-key sk-your-api-key
```

## What Gets Generated?

Each component gets its own `SKILL.md` file with:
- Component description and purpose
- Props/API documentation
- Usage examples from Storybook stories
- Implementation guidelines
- Links to your Storybook
