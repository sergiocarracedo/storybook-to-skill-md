# Data Collection

The Data Collection component provides a flexible way to display and interact with structured data. It supports sorting, filtering, selection, and various visualizations.

## Sub-components

This component includes several sub-components for specific functionalities:

-   **Callbacks**: Handles callbacks triggered by user interactions. See the Callbacks sub-page for details.
-   **Collection Actions**: Defines actions that can be performed on the entire collection. See the Collection Actions sub-page.
-   **Empty State**: Displays a message when the data collection is empty. See the Empty State sub-page.
-   **Filters**: Provides filtering capabilities for the data collection. See the Filters sub-page.
-   **Grouping**: Allows grouping of data items. See the Grouping sub-page.
-   **Internal**: Contains internal components and utilities. See the Internal sub-page.
-   **Item Actions**: Defines actions that can be performed on individual items. See the Item Actions sub-page.
-   **Miscellaneous**: Includes various utility components and functionalities. See the Miscellaneous sub-page.
-   **Navigation Filters**: Provides navigation-based filtering. See the Navigation Filters sub-page.
-   **Summary**: Displays summary information for the data collection. See the Summary sub-page.
-   **Total Items Summary**: Displays the total number of items in the collection. See the Total Items Summary sub-page.
-   **Value Display**: Renders values in a consistent format. See the Value Display sub-page.
-   **Visualizations**: Offers different ways to visualize the data. See the Visualizations sub-page.
