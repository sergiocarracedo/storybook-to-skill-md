## What is SKILL.md?

SKILL.md files are specially formatted markdown files that provide AI agents with structured knowledge about your components. They follow the [agentskills.io](https://agentskills.io) specification and include:

- Component description and purpose
- Props/API documentation
- Usage examples from Storybook stories
- Implementation guidelines
- Common patterns and variations

## Why Use This Tool?

- **Automated Documentation** - Generate component docs automatically from Storybook
- **AI-Friendly Format** - Optimized for AI agent consumption
- **Always Up-to-Date** - Regenerate on every change using caching
- **Multiple Modes** - Work with deployed Storybook or local builds
- **LLM-Powered** - Uses GPT-4, Claude, or Gemini to generate high-quality docs
- **CI/CD Ready** - GitHub Action for automated generation
